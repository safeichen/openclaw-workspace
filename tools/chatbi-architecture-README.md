## 图表概述
这是一个基于Agent Skills架构的ChatBI系统设计图，包含以下核心模块：

### 🎯 核心架构层
1. **🔍 感知层** - 多入口触发机制
   - 业务指标异常监听
   - 定时任务触发 (Cron)
   - 用户主动查询
   - 模型无关设计

2. **🧠 推理层** - 智能决策核心
   - 意图识别与任务拆解
   - 最优策略选择
   - Agent Skills编排
   - 上下文理解

3. **⚡ 行动层** - 自主执行能力
   - 自主查询执行
   - 归因分析与根因定位
   - 图表自动生成
   - 自动重试机制

4. **🔄 反馈层** - 闭环优化系统
   - 查询结果校验
   - 结论沉淀
   - 用户反馈学习
   - 执行-反馈-优化闭环

5. **💾 长记忆系统** - 越用越聪明
   - 业务知识记忆
   - 案例记忆
   - 用户画像记忆
   - 用户专属Role配置

6. **🏗️ 平台与插件体系**
   - 平台与工具分离
   - 标准化Skill/MCP接入
   - 业务场景工具Owner管理

7. **🔄 模型无关架构**
   - 不绑定单一模型
   - 支持随时切换最强模型
   - 适应不同场景的最优模型选择

## 设计理念
基于以下5个核心方向：
1. **模型无关** - 不绑定单一模型，随时可切换最强模型
2. **构建自主闭环执行机制** - 感知→推理→行动→反馈
3. **强化自主执行 + 闭环反馈** - 不止取数+图表
4. **长记忆 + 上下文持久化** - 越用越聪明
5. **平台定位和插件体系** - 平台开发和工具开发分离
