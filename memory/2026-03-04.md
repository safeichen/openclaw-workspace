## 学习经验

### 技术经验
1. **Git认证问题**：
   - Git全局配置可能影响远程URL解析
   - SSH认证比HTTPS更稳定（无需用户名密码）
   - 检查命令：`git config --global --list | grep -i url`

2. **ClawHub限制**：
   - API有速率限制，需要合理规划安装时间
   - 搜索和安装可能因限制而失败
   - 建议在非高峰时段尝试

3. **Cron任务管理**：
   - OpenClaw cron和系统crontab并存
   - 不同任务适合不同的管理方式
   - 需要定期检查任务执行状态
