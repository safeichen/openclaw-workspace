
## 微信通道修复 (2026-09-22)

**问题**: openclaw-weixin 插件在 OpenClaw 升级到 2026.3.24 后无法加载。
根因: 插件从顶层 `openclaw/plugin-sdk` 导入 `resolvePreferredOpenClawTmpDir` 等符号，
但新 SDK 已不再从顶层入口 re-export 通道插件 API，改为分散到各子路径
(account-id / text-runtime / infra-runtime / channel-runtime / command-auth / channel-config-schema)。
插件加载失败 → 整个微信通道注册失败 → 所有微信推送(AI日报/早间新闻等)静默失败。

**修复**:
1. 新建 `/root/.openclaw/extensions/openclaw-weixin/sdk-compat.ts` 兼容 shim，
   从各子路径 re-export 所需符号。
2. 将插件内 9 个文件的 `from "openclaw/plugin-sdk"` 改为指向该 shim。
3. 验证: gateway 日志中 `openclaw-weixin failed to load` 错误消失，
   `setWeixinRuntime called, runtime set successfully` 正常出现。

**遗留说明**: CLI 直接 `openclaw message send` 冷发送会报 `contextToken is required` —
这是设计如此: contextToken 是 WeChat getupdates API 每条入站消息下发的，
存在网关进程内缓存中。正常推送走网关长轮询路径，由入站消息触发，不受影响。
