## 2026-09-18 根因确认：openclaw-weixin 插件不可用
- 根因：当前安装的 openclaw@2026.3.24 的 `plugin-sdk/index.js` **不再导出** `resolvePreferredOpenClawTmpDir`（该函数仅存在于旧的 diffs.js）。weixin 插件 `src/messaging/process-message.ts` 从 `openclaw/plugin-sdk` 直接 import 该函数 → 加载即 TypeError。
