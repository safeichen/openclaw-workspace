# 功能请求记录

记录用户请求但当前不支持的功能。

## 格式说明

每个功能请求条目应包含：
- **ID**: FEAT-YYYYMMDD-XXX
- **优先级**: medium (功能请求通常设为中等优先级)
- **状态**: pending | in_progress | implemented | rejected
- **领域**: frontend | backend | infra | tests | docs | config
- **请求的功能**: 用户想要做什么
- **用户上下文**: 为什么需要，解决什么问题
- **复杂度估计**: simple | medium | complex
- **建议实现**: 如何构建，可能扩展什么
- **元数据**: 频率、相关功能等
